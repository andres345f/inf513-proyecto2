# Recursos y atribuciones

FEDER Web P2 es el proyecto académico de INF513 del grupo 29. Las dos variantes de la marca FEDER y las fotografías de producto son los recursos provistos para la demostración del equipo. Las fotografías ausentes se representan con el marcador del catálogo.

El backend utiliza Laravel. El frontend utiliza React, Leaflet, Lucide y las familias Bitter, Nunito, Outfit y Source Sans 3. El mapa conserva la atribución al proveedor de cartografía. Aquí se reproducen los avisos de Laravel, Leaflet, Lucide y de las fuentes autoalojadas. Las versiones y demás licencias de las dependencias figuran en sus paquetes y archivos de bloqueo. Cada aviso corresponde a su componente.
